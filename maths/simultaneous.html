Simultaneous equations

Rank 30 of 36 · 26 marks · 1.4% of all marks · in 6 of 24 papers

Explanations 4 ways

1The picture idea

Each equation is a straight line. The solution is the one point that is on both lines: where they cross.

2Step by step

Simultaneous equations are two equations with two unknowns. The answer must be true for both. AQA tests linear pairs, linear-and-quadratic pairs, and forming the equations from a word problem.

  1. Multiply one or both equations so that one letter has the same number in front.
  2. If the signs are different, add the equations. If the signs are the same, subtract.
  3. Solve the new equation for one letter.
  4. Put that value into one of the first equations. Find the other letter.
  5. Check both values in the other equation.

For a linear and a quadratic equation, substitute the linear one into the quadratic. Solve the quadratic. You usually get two pairs of answers.

CAUTIONMultiply every term in the equation, including the number on the right.

3Another way to see it

Two equations are two clues about the same two mystery numbers. On a graph, each equation is a line, and the answer is where the lines cross.

Elimination: make one letter have the same number in front in both equations. Then:

  • Same signs → subtract the equations.
  • Different signs → add them.

One letter disappears. Solve for the other, substitute back, then check in the other equation.

4Watch out for

  • Adding when the signs are the same (you should subtract), or the reverse.
  • Multiplying only some terms when you scale an equation. Multiply every term.
  • Sign errors: −2y − (−3y) = +y.
  • Not substituting back to find the second value.
  • Not checking the answer in the other equation.

Worked examples 3

Example 1 Warm-up

Solve x + y = 10 and x − y = 4.

  1. Different signs on y: add → 2x = 14
  2. x = 7; 7 + y = 10

Answer: x = 7, y = 3

Example 2 Standard

Solve 3x + 2y = 16 and x + 2y = 8.

  1. Same sign on 2y: subtract → 2x = 8
  2. x = 4; 4 + 2y = 8

Answer: x = 4, y = 2

Example 3 Exam-style [4 marks]

Solve the simultaneous equations 2x + 3y = 12 and 5x − 2y = 11.

  1. × 2: 4x + 6y = 24 ; × 3: 15x − 6y = 33
  2. Add: 19x = 57, so x = 3
  3. 2(3) + 3y = 12 → 3y = 6 → y = 2
  4. Check: 5(3) − 2(2) = 11 ✓

Answer: x = 3, y = 2

Q3Standard

Solve 3x + 2y = 12 and 5x − 2y = 4.

Show answer
  1. Add: 8x = 16 → x = 2
  2. 6 + 2y = 12

Answer: x = 2, y = 3

Q4Standard

Solve 4x + 3y = 18 and 2x + 5y = 16.

Show answer
  1. Double the second: 4x + 10y = 32
  2. Subtract: 7y = 14 → y = 2
  3. 4x + 6 = 18

Answer: x = 3, y = 2

Q5Exam-style

3 adult and 2 child tickets cost £42. 2 adult and 4 child tickets cost £44. Find the price of each ticket.

Show answer
  1. 3a + 2c = 42 and 2a + 4c = 44
  2. Double the first: 6a + 4c = 84; subtract: 4a = 40
  3. a = 10; 30 + 2c = 42

Answer: Adult £10, child £6

Q6Exam-style

Solve y = x + 1 and x² + y² = 25.

Show answer
  1. x² + (x + 1)² = 25 → 2x² + 2x − 24 = 0
  2. x² + x − 12 = 0 → (x + 4)(x − 3) = 0
  3. x = 3, y = 4 or x = −4, y = −3

Answer: (3, 4) and (−4, −3)
