Sequences

Explanations 4 ways

1The picture idea

Draw each term as dots. 3, 8, 15, 24 are squares with two extra lines of dots. The n² is a real square you can see.

2Step by step

A sequence is a list of numbers that follows a rule. The nth term is a formula for any term. AQA tests linear sequences, quadratic sequences, geometric sequences and Fibonacci-type sequences.

To find the nth term of a quadratic sequence:

  1. Find the first differences between terms.
  2. Find the second differences. They must be the same.
  3. Halve the second difference. This is the number in front of n².
  4. Subtract that n² part from each term.
  5. Find the nth term of what is left. It is linear. Add it to the n² part.
  6. Check your formula with n = 1 and n = 2.

CAUTIONThe coefficient of n² is half the second difference, not the full second difference.

3Another way to see it

A linear sequence is a times table that has been shifted. For 5, 8, 11, 14: it goes up in 3s, so it is the 3 times table (3, 6, 9, 12) moved up 2. So the nth term is 3n + 2.

A quadratic sequence has differences that change, but the second differences are the same. Half the second difference is the number in front of n². Take away that n² part, and what is left is linear.

A geometric sequence multiplies by the same number each time (3, 6, 12, 24…).

4Watch out for

  • Writing n + 3 for a sequence that goes up in 3s. It should be 3n + something.
  • Forgetting to halve the second difference.
  • Losing a negative sign: if it goes down in 3s, the term starts −3n.
  • Starting with n = 0. The first term is n = 1.
  • To check if a number is in the sequence, set the nth term equal to it. If n is not a whole number, it is not in the sequence.

Worked examples 3

Example 1 Warm-up

Find the nth term of 5, 8, 11, 14, …

  1. Difference 3 → 3n
  2. 3n gives 3, 6, 9…; each term is 2 more

Answer: 3n + 2

Example 2 Standard

Is 100 a term in the sequence 3n + 2? Explain.

  1. 3n + 2 = 100 → 3n = 98
  2. n = 32.67, not a whole number

Answer: No, n is not a whole number

Example 3 Exam-style [3 marks]

Find an expression for the nth term of the sequence 3, 8, 15, 24, 35, …

  1. First differences: 5, 7, 9, 11. Second difference: 2
  2. ½ × 2 = 1, so the sequence starts with n²
  3. Terms − n²: 3 − 1, 8 − 4, 15 − 9, … = 2, 4, 6, 8, 10 → 2n
  4. Check n = 5: 25 + 10 = 35 ✓

Answer: n² + 2n
