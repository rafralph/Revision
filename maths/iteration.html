Iteration

Explanations 4 ways

1The picture idea

Feed each answer back into the formula. On a graph, the steps make a staircase between y = x and the curve that closes in on the solution.

2Step by step

Iteration finds an approximate solution by repeating a formula. AQA tests the sign-change check, rearranging an equation into an iteration formula, and working out x₁, x₂, x₃.

  1. To show a solution is between a and b, work out f(a) and f(b). One must be negative and one positive.
  2. Put x₀ into the formula. The result is x₁.
  3. Put x₁ into the formula. The result is x₂. Continue.
  4. On a calculator, type x₀ and press =. Type the formula with ANS in place of xₙ. Press = for each new value.
  5. Stop when the values agree to the accuracy that you need.

CAUTIONWrite down each value to at least 4 decimal places. Do not round until the end.

3Another way to see it

Some equations are too hard to solve exactly. Iteration is a clever guess-and-improve loop.

  1. Rearrange the equation into x = (something with x).
  2. Put in a starting value x₀.
  3. The answer is x₁. Put x₁ back in to get x₂, and so on.

On a calculator: type x₀ and press =. Type the formula using Ans for x, then keep pressing =.

A change of sign shows a solution exists: if f(1) is negative and f(2) is positive, the graph crosses zero between 1 and 2.

4Watch out for

  • Rounding each answer before putting it back in. Keep the full calculator value.
  • Mixing up xₙ₊₁ (the next value) and xₙ (the current one).
  • Rearranging wrongly: check you get back to the original equation.
  • For a change of sign, not stating both signs and the conclusion.
  • Writing x₃ when the question asks for x₂.

Worked examples 3

Example 1 Warm-up

Use xₙ₊₁ = 3 + 1/xₙ with x₀ = 1 to find x₁ and x₂.

  1. x₁ = 3 + 1/1 = 4
  2. x₂ = 3 + 1/4

Answer: x₁ = 4, x₂ = 3.25

Example 2 Standard

x³ − 3x − 5 = 0 rearranges to x = ∛(3x + 5). Use x₀ = 2 to find x₁ and x₂ to 4 d.p.

  1. x₁ = ∛11 = 2.2240
  2. x₂ = ∛(3 × 2.2239… + 5) = 2.2684

Answer: x₁ = 2.2240, x₂ = 2.2684

Example 3 Exam-style [4 marks]

(a) Show that x³ − 3x − 5 = 0 has a solution between 2 and 3. (b) Use xn+1 = ∛(3xn + 5) with x₀ = 2 to find x₁, x₂ and x₃.

  1. (a) f(2) = 8 − 6 − 5 = −3 ; f(3) = 27 − 9 − 5 = 13
  2. Sign change, so there is a solution between 2 and 3
  3. (b) x₁ = ∛11 = 2.2240 ; x₂ = ∛(3 × 2.2240 + 5) = 2.2684
  4. x₃ = ∛(3 × 2.2684 + 5) = 2.2770

Answer: x₁ = 2.2240, x₂ = 2.2684, x₃ = 2.2770

Practice 6 questions · easy to exam-style

Try each one first. Then open the answer to check your working.

Q1Warm-up

Use xₙ₊₁ = xₙ/2 + 3 with x₁ = 4 to find x₂ and x₃.

Show answer
  1. x₂ = 2 + 3 = 5
  2. x₃ = 2.5 + 3

Answer: x₂ = 5, x₃ = 5.5

Q2Warm-up

Show that x³ + x − 3 = 0 has a solution between 1 and 2.

Show answer
  1. f(1) = 1 + 1 − 3 = −1
  2. f(2) = 8 + 2 − 3 = 7

Answer: Sign changes, so a solution lies between 1 and 2

Q3Standard

Show that x² − 5x + 2 = 0 can be written as x = 5 − 2/x.

Show answer
  1. Divide every term by x: x − 5 + 2/x = 0

Answer: x = 5 − 2/x

Q4Standard

Use xₙ₊₁ = 5 − 2/xₙ with x₀ = 4 to find x₃ to 4 d.p.

Show answer
  1. x₁ = 4.5
  2. x₂ = 4.5556
  3. x₃ = 4.5610

Answer: x₃ = 4.5610

Q5Exam-style

Use xₙ₊₁ = √(10 − xₙ) with x₀ = 3 to find x₃ to 3 d.p.

Show answer
  1. x₁ = √7 = 2.6458
  2. x₂ = 2.7119
  3. x₃ = 2.6997

Answer: x₃ = 2.700

Q6Exam-style

Show that x³ − 2x − 5 = 0 has a root between 2 and 2.1.

Show answer
  1. f(2) = 8 − 4 − 5 = −1
  2. f(2.1) = 9.261 − 4.2 − 5 = 0.061

Answer: Sign changes from − to +, so a root lies between 2 and 2.1
