Quadratics

Explanations 4 ways

1The picture idea

Completing the square is a real square. Split 6x into two strips of 3x around x². One 3 by 3 corner is missing.

2Step by step

A quadratic has an x² term. AQA tests factorising, the quadratic formula, completing the square, quadratic inequalities and turning points.

To solve x² + bx + c = 0 by completing the square:

  1. Halve b. Write (x + b/2)².
  2. Subtract (b/2)². This removes the extra corner.
  3. Add c. Simplify the number.
  4. Make the bracket the subject. Take the square root of both sides.
  5. Write ± in front of the square root. Then solve for x.

The completed square (x + p)² + q gives the turning point (−p, q).

CAUTIONA square root has two values, + and −. Give both solutions.

3Another way to see it

A quadratic graph is a U-shaped curve (a parabola). Solving x² + bx + c = 0 means finding where the curve crosses the x-axis. There can be 2, 1 or 0 crossing points.

There are three routes to the answer:

  1. Factorise into two brackets. If two things multiply to 0, one of them must be 0.
  2. Quadratic formula: always works. Use it when the question says "give your answer to 2 decimal places".
  3. Complete the square: (x + p)² + q. It also tells you the turning point (−p, q).

4Watch out for

  • Forgetting the ± when you square-root, so you lose one answer.
  • Not rearranging to '= 0' before factorising.
  • Squaring a negative b wrongly in the formula: (−3)² = +9.
  • Wrong sign in the completed-square bracket: x² − 8x → (x − 4)².
  • Dividing both sides by x, which loses the solution x = 0.

Worked examples 3

Example 1 Warm-up

Solve x² − 5x + 6 = 0.

  1. Two numbers that multiply to 6 and add to −5: −2 and −3
  2. (x − 2)(x − 3) = 0
  3. x − 2 = 0 or x − 3 = 0

Answer: x = 2 or x = 3

Example 2 Standard

Solve 2x² + 3x − 4 = 0. Give your answers to 2 decimal places.

  1. a = 2, b = 3, c = −4
  2. b² − 4ac = 9 + 32 = 41
  3. x = (−3 ± √41) ÷ 4

Answer: x = 0.85 or x = −2.35

Example 3 Exam-style [3 marks]

Solve x² + 6x − 4 = 0 by completing the square. Give your answers in the form a ± √b.

  1. x² + 6x = (x + 3)² − 9
  2. x² + 6x − 4 = (x + 3)² − 13 = 0
  3. (x + 3)² = 13, so x + 3 = ±√13
  4. Decimal check: x = 0.606 or x = −6.606

Answer: x = −3 ± √13

Q2Warm-up

Show answer
  1. x − 3 = 0 or x + 5 = 0

Answer: x = 3 or x = −5

Q3Standard

Solve x² + 2x − 15 = 0.

Show answer
  1. Multiply to −15, add to +2: +5 and −3
  2. (x + 5)(x − 3) = 0

Answer: x = −5 or x = 3

Q4Standard

Write x² − 8x + 5 in the form (x − a)² − b. Write down the turning point of y = x² − 8x + 5.

Show answer
  1. Half of −8 is −4: (x − 4)² = x² − 8x + 16
  2. x² − 8x + 5 = (x − 4)² − 16 + 5

Answer: (x − 4)² − 11; turning point (4, −11)

Q5Exam-style

Solve 3x² − x − 5 = 0. Give your answers to 2 decimal places.

Show answer
  1. a = 3, b = −1, c = −5
  2. b² − 4ac = 1 + 60 = 61
  3. x = (1 ± √61) ÷ 6

Answer: x = 1.47 or x = −1.14

Q6Exam-style

Solve 2x² + 5x − 3 = 0 by factorising.

Show answer
  1. a × c = −6: numbers 6 and −1
  2. 2x² + 6x − x − 3 = 2x(x + 3) − 1(x + 3)
  3. (2x − 1)(x + 3) = 0

Answer: x = ½ or x = −3
