Writing complete programs

Paper 1 · 64 marks · 17.8% of all marks · in 2 of 4 papers

The picture ideaA long program is just small pieces in the right order. Split the task into input, process and output, then write and check one piece at a time.

Explanation (ASD-STE100 style)

The last questions on Paper 1 ask you to write a complete Python program. They are worth 6 to 11 marks each. Marks are given for each correct part, so a partly working program still scores.

  1. Read the task twice. Underline every input, every output and every rule.
  2. Set up the variables you need, such as counters and totals.
  3. Choose the right structure: a for loop for a fixed number of repeats, a while loop to repeat until a condition changes.
  4. Put input inside the loop if it must be asked more than once.
  5. Put the final output after the loop.
  6. Trace your code with one test value before you move on.

CAUTIONIndentation matters in Python. Code inside a loop or if must be indented.

Example exam question

Write a Python program that asks the user to enter five test scores. The program must output the total and the highest score.
[6 marks]
  1. Set total = 0 and highest = 0 before the loop
  2. Use for i in range(5): to repeat five times
  3. Inside: score = int(input("Score: ")) and total = total + score
  4. Inside: if score > highest: highest = score
  5. After the loop: print(total, highest)

Answer: A loop of 5 inputs, a running total and a running maximum

total = 0
highest = 0
for i in range(5):
    score = int(input("Score: "))
    total = total + score
    if score > highest:
        highest = score
print("Total:", total)
print("Highest:", highest)

Databases and SQL

Paper 2 · 25 marks · 6.9% of all marks · in 2 of 4 papers

The picture ideaRead a query like a sentence: choose these columns, from this table, but only the rows that pass this test.

Explanation (ASD-STE100 style)

A relational database stores data in tables. A record is a row. A field is a column. A primary key uniquely identifies each record. A foreign key links to the primary key of another table.

  1. SELECT lists the fields to show. * means all fields.
  2. FROM names the table.
  3. WHERE gives the condition. Join conditions with AND or OR.
  4. ORDER BY sorts: ASC (smallest first) or DESC.
  5. INSERT INTO, UPDATE … SET and DELETE FROM change the data.

CAUTIONPut text values in quotes: WHERE Rating = 'PG'. Do not put numbers in quotes.

Example exam question

Using the Film table, write an SQL statement to (a) list the titles of all films with rating U, and (b) change the rating of Elf to U.
[4 marks]
  1. (a) SELECT Title FROM Film WHERE Rating = 'U'
  2. Result: Up, Wish
  3. (b) UPDATE Film SET Rating = 'U' WHERE FilmID = 4
  4. Use the primary key in WHERE so only one record changes

Answer: (a) SELECT Title FROM Film WHERE Rating = 'U' (b) UPDATE Film SET Rating = 'U' WHERE FilmID = 4

Algorithms, trace tables and pseudocode

Paper 1 · 22 marks · 6.1% of all marks · in 2 of 4 papers

The picture ideaA trace table is you playing the part of the computer: one line at a time, writing down every change.

Explanation (ASD-STE100 style)

An algorithm is a sequence of steps that solves a problem. It can be shown in pseudocode, as a flowchart or as program code. Decomposition breaks a problem into smaller parts. Abstraction removes details that are not needed.

  1. Make one column for each variable, plus one for output.
  2. Go through the code one line at a time.
  3. Write a new value only when it changes.
  4. For a loop, check the condition each time round.
  5. Stop when the loop condition is false. Write the final output.

CAUTIONrange(1, 4) gives 1, 2, 3. It stops before 4.

Example exam question

Complete a trace table for this code when the user enters 13.
n = int(input())
steps = 0
while n != 1:
    if n % 2 == 0:
        n = n // 2
    else:
        n = 3 * n + 1
    steps = steps + 1
print(steps)
[4 marks]
  1. n: 13 → 40 → 20 → 10 → 5 → 16 → 8 → 4 → 2 → 1
  2. steps goes up by 1 each time round the loop: 1, 2, … 9
  3. The loop stops when n = 1
  4. Output: 9

Answer: Output 9

Validation, testing and errors

Paper 1 · 20 marks · 5.6% of all marks · in 2 of 4 papers

The picture ideaGood testing attacks the edges. Most bugs live at the boundary between accepted and rejected values.

Explanation (ASD-STE100 style)

Validation checks that input is sensible and in the right form. Authentication checks who a user is. Testing checks that a program works. AQA tests validation code, test data and error types.

  1. Range check: is the value between limits?
  2. Length check, presence check and type check are also common.
  3. Use a while loop to ask again until the input is valid.
  4. Choose test data: normal (inside the range), boundary (at and just outside the edges) and erroneous (wrong type or far outside).
  5. Syntax error: breaks the rules of the language, so the program will not run. Logic error: runs but gives the wrong result.

CAUTIONValidation cannot check that data is true. A valid age can still be the wrong age.

Example exam question

A program accepts a quantity from 1 to 50. Give one example each of normal, boundary and erroneous test data, and explain the difference between a syntax error and a logic error.
[4 marks]
  1. Normal: 25
  2. Boundary: 1 or 50 (or 0 / 51 just outside)
  3. Erroneous: 100 or "ten"
  4. Syntax error: code breaks language rules and will not run; logic error: code runs but gives a wrong result

Answer: 25; 50; "ten"; syntax stops it running, logic gives wrong output

Networks and protocols

Paper 2 · 19 marks · 5.3% of all marks · in 2 of 4 papers

The picture ideaProtocols are agreed rules, and layers split one huge job into four smaller jobs. Each layer only talks to the layers next to it.

Explanation (ASD-STE100 style)

A network is two or more computers connected to share data and resources. A LAN covers a small area. A WAN covers a large area. A PAN connects devices close to one person, for example with Bluetooth.

  1. Star topology: every device connects to a central switch. One cable failure only affects one device.
  2. Bus topology: all devices share one cable. Cheap, but a cable failure stops the network.
  3. Wired networks are faster and more secure. Wireless networks are flexible.
  4. The TCP/IP model has four layers: application, transport, internet and link.
  5. Protocols: HTTP/HTTPS (web), SMTP (send email), IMAP (receive email), FTP (files), TCP and UDP (transport), IP (addressing).

CAUTIONHTTPS is HTTP with encryption. It does not stop viruses.

Example exam question

(a) Give two advantages of a star topology. (b) Name the protocol used to send an email, and the layer of the TCP/IP model it belongs to.
[4 marks]
  1. (a) If one cable fails, the other devices still work
  2. (a) It is easy to add new devices / performance stays good
  3. (b) SMTP
  4. (b) Application layer

Answer: (a) fault-tolerant; easy to add devices (b) SMTP, application layer

Binary, hex and binary arithmetic

Paper 2 · 18 marks · 5.0% of all marks · in 2 of 4 papers

The picture ideaEvery binary column is worth double the one to its right. Hex is just a short way to write four bits at a time.

Explanation (ASD-STE100 style)

Computers store all data in binary (base 2). Hexadecimal (base 16) is a short way for people to write binary. AQA tests conversions, binary addition and binary shifts, for numbers up to 255.

  1. Write the column values: 128, 64, 32, 16, 8, 4, 2, 1.
  2. Denary to binary: put a 1 under the biggest value that fits, subtract, and repeat.
  3. Binary to hex: split into two groups of 4 bits. Convert each group (10 = A … 15 = F).
  4. Binary addition: 1 + 1 = 10 (write 0, carry 1); 1 + 1 + 1 = 11.
  5. A left shift of n places multiplies by 2ⁿ. A right shift divides by 2ⁿ.

CAUTIONIf an 8-bit addition gives a 9th bit, that is an overflow error.

Example exam question

(a) Convert 173 to 8-bit binary. (b) Convert your answer to hexadecimal. (c) Apply a left shift of 1 to 00101101 and give the result in denary.
[4 marks]
  1. (a) 173 − 128 = 45; 45 − 32 = 13; 13 − 8 = 5; 5 − 4 = 1; 1 − 1 = 0 → 10101101
  2. (b) 1010 = 10 = A; 1101 = 13 = D → AD
  3. (c) 00101101 = 45; shift left 1 → 01011010
  4. = 90 (45 × 2)

Answer: (a) 10101101 (b) AD (c) 90

Cyber security

Paper 2 · 18 marks · 5.0% of all marks · in 2 of 4 papers

The picture ideaMost attacks target people, not machines. That is why the defences include training and checks on people, not only software.

Explanation (ASD-STE100 style)

Cyber security protects networks, computers, programs and data from attack, damage or unauthorised access. AQA tests threats, social engineering, malware and ways to prevent attacks.

  1. Social engineering tricks people: phishing (fake emails), blagging (an invented story), shouldering (watching someone enter a PIN).
  2. Malware is harmful software: viruses, trojans and spyware.
  3. Other threats: weak passwords, misconfigured access rights, removable media, unpatched software.
  4. Defences: biometrics, strong passwords, CAPTCHA, email confirmation, automatic software updates.
  5. Penetration testing: experts attack a system on purpose to find weaknesses.

CAUTIONMatch each defence to a specific threat in your answer, for example "CAPTCHA stops automated bots".

Example exam question

A bank receives reports that customers have been sent emails asking for their login details. (a) Name this type of attack. (b) Describe two ways the bank can protect its customers.
[5 marks]
  1. (a) Phishing (a form of social engineering)
  2. (b) Tell customers the bank will never ask for passwords by email
  3. (b) Use two-step authentication, so a stolen password alone is not enough
  4. (b) Other valid answers: email filtering, customer education, biometric login

Answer: (a) Phishing (b) e.g. education; two-step authentication

Subroutines and parameters

Paper 1 · 16 marks · 4.4% of all marks · in 2 of 4 papers

The picture ideaA function is a small machine inside your program: parameters go in, a return value comes out, and its working stays private.

Explanation (ASD-STE100 style)

A subroutine is a named block of code that does one task. A function returns a value. A procedure does not. AQA tests writing subroutines, parameters, return values, and local and global variables.

  1. Define it with def name(parameters):.
  2. Parameters receive the values passed in when it is called.
  3. Use return to send a result back.
  4. A local variable exists only inside the subroutine.
  5. Advantages: code can be reused, tested separately, and shared between programmers. Programs are easier to read (structured programming).

CAUTIONprint inside a function is not the same as return. If the question says "return", use return.

Example exam question

Write a Python function called isEven that takes an integer and returns True if it is even and False if it is odd.
[3 marks]
  1. Define the function with one parameter
  2. Use MOD (%) to test the remainder when divided by 2
  3. Return True or False

Answer: def isEven(n): return n % 2 == 0

def isEven(n):
    if n % 2 == 0:
        return True
    else:
        return False

print(isEven(4), isEven(7))   # True False

Ethical, legal and environmental issues

Paper 2 · 15 marks · 4.2% of all marks · in 2 of 4 papers

The picture ideaLook at any technology through three lenses (ethical, legal and environmental) and always show both sides.

Explanation (ASD-STE100 style)

This topic is often a 9-mark extended answer about a new technology, such as self-driving cars, facial recognition or wearable devices. Marks are for a range of points, explained, and linked to the example.

  1. Ethical: privacy, fairness, effect on jobs, who is responsible when something goes wrong.
  2. Legal: Data Protection Act (personal data), Computer Misuse Act (hacking), copyright law.
  3. Environmental: energy use, e-waste, rare materials; but also less travel or paper.
  4. For each point, explain the effect on people.
  5. Give benefits and drawbacks, then a short conclusion.

CAUTIONA list of words earns few marks. Each point needs an explanation and a link to the scenario.

Example exam question

A city plans to use cameras with facial recognition in the town centre. Discuss the ethical, legal and environmental issues.
[9 marks]
  1. Ethical: could reduce crime, but people are watched without consent; errors may target innocent people
  2. Legal: images are personal data under the Data Protection Act; must be stored securely and not kept too long
  3. Environmental: cameras and servers use electricity and create e-waste when replaced
  4. Conclusion: benefits for safety must be balanced against privacy, with clear rules

Answer: Range of points across all three areas, each explained, both sides, linked to cameras

Selection and iteration

Paper 1 · 12 marks · 3.3% of all marks · in 2 of 4 papers

The picture ideaSelection chooses a path; iteration repeats one. A for loop counts, a while loop waits for something to change.

Explanation (ASD-STE100 style)

All programs are built from three structures: sequence, selection and iteration.

  1. Selection: if, elif, else. Python runs the first branch whose condition is true.
  2. Definite iteration: for i in range(n): repeats a fixed number of times.
  3. Indefinite iteration: while condition: repeats until the condition is false.
  4. Structures can be nested: a loop inside a loop, or an if inside a loop.
  5. Make sure something inside a while loop changes, or the loop never ends.

CAUTIONOrder elif conditions from the highest boundary down. Otherwise an earlier branch catches values first.

Example exam question

What does this code print?
for i in range(2, 11, 3):
    print(i)
[2 marks]
  1. range(2, 11, 3) starts at 2, adds 3 each time, and stops before 11
  2. Values: 2, 5, 8

Answer: 2, 5, 8 (each on a new line)

Boolean logic and logic gates

Paper 2 · 12 marks · 3.3% of all marks · in 2 of 4 papers

The picture ideaA truth table is a complete list of every possible input. Build it one column at a time and you cannot miss a case.

Explanation (ASD-STE100 style)

Logic gates process binary inputs. AQA tests AND, OR, NOT and XOR gates, truth tables, logic circuits and Boolean expressions.

  1. AND: output 1 only when both inputs are 1.
  2. OR: output 1 when at least one input is 1.
  3. NOT: output is the opposite of the input.
  4. XOR: output 1 when exactly one input is 1.
  5. For a truth table, list every input combination (2 inputs: 4 rows; 3 inputs: 8 rows). Add one column for each gate.

CAUTIONWork out the brackets first, as in maths.

Example exam question

Complete the truth table for Q = (A AND B) OR (NOT C). How many rows give Q = 1?
[4 marks]
  1. List the 8 combinations of A, B, C
  2. Column A AND B: 1 only in the last two rows
  3. Column NOT C: 1 when C = 0
  4. Q = 1 in rows 1, 3, 5, 7 and 8

Answer: Q = 1 in 5 of the 8 rows

Lists, arrays and records

Paper 1 · 11 marks · 3.1% of all marks · in 2 of 4 papers

The picture ideaA list is a row of numbered boxes. The numbers start at zero, so the first box is box 0.

Explanation (ASD-STE100 style)

A data structure stores many values under one name. In Python, lists are used for arrays. A two-dimensional list is a list of lists, like a table. A record groups related fields of different types.

  1. Create a list: scores = [12, 7, 19, 4, 15].
  2. Indexes start at 0: scores[0] is 12.
  3. Use len(scores) for the number of items.
  4. Loop through every item: for s in scores:.
  5. 2D list: grid[row][column].

CAUTIONThe last index is len(list) − 1. scores[5] gives an error for a list of 5 items.

Example exam question

temps = [14, 19, 11, 22, 17]. Write Python code to output the index of the highest temperature.
[4 marks]
  1. Store the index of the highest so far, starting at 0
  2. Loop through indexes 1 to 4 with range(1, len(temps))
  3. If temps[i] > temps[best], set best = i
  4. Output best after the loop (3)

Answer: 3

temps = [14, 19, 11, 22, 17]
best = 0
for i in range(1, len(temps)):
    if temps[i] > temps[best]:
        best = i
print(best)   # 3

Sorting algorithms

Paper 1 · 11 marks · 3.1% of all marks · in 2 of 4 papers

The picture ideaBubble sort lets the largest value float to the end on each pass. Merge sort splits until each piece is trivially sorted, then zips pieces together.

Explanation (ASD-STE100 style)

AQA tests bubble sort and merge sort: how they work, tracing them, and comparing them.

  1. Bubble sort: compare items 1 and 2; swap if out of order. Then items 2 and 3, and so on to the end. That is one pass.
  2. After each pass, the largest remaining item is in its final place.
  3. Stop when a pass makes no swaps.
  4. Merge sort: split the list in half again and again until each list has one item.
  5. Merge pairs of lists in order until one list remains.

Merge sort is faster for large lists. Bubble sort is simpler and uses less memory.

CAUTIONIn a "first pass" question, write the list after one complete pass, not after one swap.

Example exam question

(a) Show the list [5, 1, 4, 2, 8] after the first pass of a bubble sort. (b) Give one advantage of merge sort over bubble sort.
[3 marks]
  1. (a) Swap 5 and 1, then 5 and 4, then 5 and 2; 5 and 8 stay
  2. [1, 4, 2, 5, 8]
  3. (b) Merge sort is much faster (fewer comparisons) for large lists

Answer: (a) [1, 4, 2, 5, 8] (b) faster on large lists

Programming languages and translators

Paper 2 · 11 marks · 3.1% of all marks · in 2 of 4 papers

The picture ideaThe CPU only understands binary. Every other language is a translation layer, built for people rather than for the machine.

Explanation (ASD-STE100 style)

Processors run machine code (binary). AQA tests high-level and low-level languages and the three types of translator.

  1. High-level languages (Python, C#) are easy to read and write, and work on different processors.
  2. Low-level languages: machine code and assembly language. Each assembly instruction matches one machine code instruction.
  3. Low-level code gives direct control of hardware, fast code and small programs. It is used in embedded systems.
  4. Compiler: translates the whole program into machine code once. The result runs fast and without the compiler.
  5. Interpreter: translates and runs one line at a time. Easy to debug, but slower. Assembler: assembly → machine code.

CAUTIONA compiler reports errors after translating everything. An interpreter stops at the first error line.

Example exam question

(a) Give two reasons why a programmer might write in a high-level language. (b) Explain one advantage of a compiler over an interpreter.
[4 marks]
  1. (a) Easier to read and write / closer to English
  2. (a) Portable: runs on different types of processor
  3. (b) The compiled program runs faster
  4. (b) Or: the user does not need the translator to run it / source code stays private

Answer: (a) readable; portable (b) compiled code runs faster without the translator

Hardware, software and the OS

Paper 2 · 10 marks · 2.8% of all marks · in 2 of 4 papers

The picture ideaThe operating system is the manager in the middle: it shares the hardware fairly between programs and users.

Explanation (ASD-STE100 style)

Hardware is the physical parts of a computer. Software is the programs. System software runs and manages the computer. Application software lets users do tasks.

  1. The operating system (OS) manages the processor: it schedules which program runs.
  2. It manages memory: it gives each program space in RAM.
  3. It manages peripherals using drivers.
  4. It manages users (log-ins and access rights) and files.
  5. Utility software maintains the computer: encryption, defragmentation, data compression and backup.

CAUTIONAn operating system is system software. A web browser is application software.

Example exam question

Describe three functions of an operating system.
[3 marks]
  1. Processor management: schedules which program uses the CPU
  2. Memory management: allocates RAM to programs
  3. Peripheral management: controls devices such as printers using drivers

Answer: Any three of: processor, memory, peripheral, user, file management (described)

Memory and storage

Paper 2 · 10 marks · 2.8% of all marks · in 2 of 4 papers

The picture ideaMain memory is a desk (fast, small, cleared at the end of the day); secondary storage is a filing cabinet (slower, bigger, permanent).

Explanation (ASD-STE100 style)

Main memory holds data and programs that are in use. RAM is volatile: it loses data when the power is off. ROM is non-volatile and stores the boot program. Secondary storage keeps data permanently.

  1. Magnetic (hard disk): cheap per GB, large capacity, has moving parts.
  2. Optical (DVD, Blu-ray): cheap, portable, low capacity, easily scratched.
  3. Solid state (SSD, USB stick): fast, small, no moving parts, so it is robust.
  4. Choose by capacity, speed, portability, durability, reliability and cost.
  5. Cloud storage: data on remote servers. Access anywhere, but needs internet.

CAUTIONCache is memory inside the CPU. It is faster than RAM but much smaller.

Example exam question

A student needs storage for a laptop she carries to school every day. Recommend a type of secondary storage and justify your choice.
[3 marks]
  1. Solid state (SSD)
  2. No moving parts, so it is not damaged if the laptop is dropped or moved
  3. Fast access and low power use (longer battery life)

Answer: Solid state: robust, fast, low power

String handling

Paper 1 · 9 marks · 2.5% of all marks · in 2 of 4 papers

The picture ideaA string is a row of character boxes numbered from 0. A slice takes boxes from the start index up to, but not including, the end index.

Explanation (ASD-STE100 style)

A string is a sequence of characters. AQA tests length, position, substrings, concatenation, character codes and case.

  1. len(word) gives the number of characters.
  2. word[0] is the first character.
  3. word[a:b] gives characters from index a up to b − 1.
  4. + joins strings (concatenation). Use str() to join a number.
  5. ord("A") gives 65. chr(65) gives "A". .upper() and .lower() change case.

CAUTION"Score: " + 5 causes an error. Write "Score: " + str(5).

Example exam question

name = "Raphael". Write the output of: (a) print(len(name)) (b) print(name[0:4]) (c) print(name[-1].upper())
[3 marks]
  1. (a) R-a-p-h-a-e-l has 7 characters
  2. (b) indexes 0 to 3: Raph
  3. (c) the last character is 'l', upper case: L

Answer: (a) 7 (b) Raph (c) L

Representing images

Paper 2 · 9 marks · 2.5% of all marks · in 2 of 4 papers

The picture ideaAn image is a grid of pixels, and each pixel is a binary number. More pixels or more colours means more bits.

Explanation (ASD-STE100 style)

A bitmap image is made of pixels. Each pixel's colour is stored in binary. AQA tests colour depth, resolution and file size calculations.

  1. Resolution = width × height in pixels.
  2. Colour depth = bits per pixel. n bits give 2ⁿ colours.
  3. File size (bits) = width × height × colour depth.
  4. Divide by 8 for bytes, then by 1000 for kB, and again for MB.
  5. Higher resolution or colour depth: better quality but a bigger file.

CAUTIONCheck whether the question wants bits, bytes or kilobytes.

Example exam question

An image is 800 pixels wide and 600 pixels high, with a colour depth of 24 bits. Calculate the file size in kilobytes.
[3 marks]
  1. Bits = 800 × 600 × 24 = 11,520,000
  2. Bytes = 11,520,000 ÷ 8 = 1,440,000
  3. kB = 1,440,000 ÷ 1000

Answer: 1440 kB

19

Representing sound

Paper 2 · 8 marks · 2.2% of all marks · in 2 of 4 papers

The picture ideaSound is stored by measuring the wave many times a second. More measurements, and more precise ones, give better sound and bigger files.

Explanation (ASD-STE100 style)

Sound is analogue. It is converted to digital by sampling the amplitude at regular intervals. AQA tests sample rate, sample resolution and file size.

  1. Sample rate: the number of samples per second, in hertz (Hz).
  2. Sample resolution: the number of bits per sample.
  3. File size (bits) = sample rate × sample resolution × length in seconds.
  4. Divide by 8 for bytes.
  5. Higher rate or resolution: closer to the real sound, but a bigger file.

CAUTIONConvert minutes to seconds first.

Example exam question

A 10-second clip is recorded at 44,100 Hz with a sample resolution of 16 bits. Calculate the file size in kilobytes.
[3 marks]
  1. Bits = 44,100 × 16 × 10 = 7,056,000
  2. Bytes = 7,056,000 ÷ 8 = 882,000

The CPU and the fetch–execute cycle

Paper 2 · 8 marks · 2.2% of all marks · in 1 of 4 papers

The picture ideaThe CPU does one simple loop, billions of times a second: fetch an instruction, decode it, execute it.

Explanation (ASD-STE100 style)

The CPU (central processing unit) processes data and instructions. AQA tests its parts, the fetch–execute cycle and factors that affect performance.

  1. Control unit: decodes instructions and controls the other parts.
  2. ALU (arithmetic logic unit): does calculations and logical comparisons.
  3. Clock: sends pulses that time each step. Registers: tiny, very fast storage inside the CPU.
  4. Fetch the next instruction from memory; decode it; execute it; repeat.
  5. Performance improves with higher clock speed, more cores and more cache.

In the von Neumann architecture, data and instructions share the same memory.

CAUTIONMore cores only help if the software can split the work into parallel tasks.

Example exam question

(a) Describe the fetch–execute cycle. (b) Explain why increasing cache size can improve performance.
[5 marks]
  1. (a) Fetch: the next instruction is copied from main memory into the CPU
  2. (a) Decode: the control unit works out what the instruction means
  3. (a) Execute: the instruction is carried out (for example by the ALU); then repeat
  4. (b) Cache is faster than RAM and close to the processor
  5. (b) More frequently used instructions/data can be kept there, so fewer slow RAM accesses

Answer: Fetch → decode → execute; cache reduces slow trips to RAM

Data compression

Paper 2 · 7 marks · 1.9% of all marks · in 2 of 4 papers

The picture ideaCompression removes repetition. Run-length encoding counts repeats; Huffman coding gives the most common symbols the shortest codes.

Explanation (ASD-STE100 style)

Compression makes files smaller, so they use less storage and transfer faster. AQA tests run-length encoding (RLE) and Huffman coding.

  1. RLE: replace each run of identical values with a count and the value. AAAABBB → 4A 3B.
  2. RLE works well when data has long runs, such as simple images.
  3. Huffman coding: build a tree from character frequencies.
  4. Common characters get short codes; rare characters get longer codes.
  5. Bits needed = Σ (frequency × code length). Compare with 7 bits per character for ASCII.

CAUTIONRLE can make data bigger if there are no runs: ABCD → 1A1B1C1D.

Example exam question

(a) Show AAAABBBCCD using run-length encoding. (b) Using the Huffman codes in the table, how many bits are needed? (c) How many bits would 7-bit ASCII need?
[4 marks]
  1. (a) 4A 3B 2C 1D
  2. (b) 4×1 + 3×2 + 2×3 + 1×3
  3. = 19 bits
  4. (c) 10 characters × 7 bits = 70 bits

Answer: (a) 4A3B2C1D (b) 19 bits (c) 70 bits

Searching algorithms

Paper 1 · 5 marks · 1.4% of all marks · in 1 of 4 papers

The picture ideaA binary search throws away half of the list with every comparison, so even a huge sorted list needs only a few steps.

Explanation (ASD-STE100 style)

AQA tests linear search and binary search: how they work, tracing them, and comparing them.

  1. Linear search: check each item from the start until you find the target or reach the end. Works on any list.
  2. Binary search needs a sorted list.
  3. Look at the middle item. If it is the target, stop.
  4. If the target is smaller, keep the left half; if larger, keep the right half.
  5. Repeat on the half that is left.

Binary search is much faster on large lists. Linear search is simpler and works on unsorted data.

CAUTIONIf the list has an even number of items, use the rule in the question to pick the middle (usually the lower of the two).

Example exam question

Show the stages of a binary search for 23 in [3, 8, 12, 15, 23, 31, 42]. How many items are compared?
[3 marks]
  1. Middle is 15; 23 > 15, so search [23, 31, 42]
  2. Middle is 31; 23 < 31, so search [23]
  3. Middle is 23: found after 3 comparisons

Answer: 3 comparisons (15, 31, 23)

Units of information

Paper 2 · 4 marks · 1.1% of all marks · in 2 of 4 papers

The picture ideaEvery step up the ladder of units is a thousand times bigger, and every byte is eight bits.

Explanation (ASD-STE100 style)

AQA tests the units of information and converting between them.

  1. 1 bit is a single 0 or 1. 4 bits = 1 nibble. 8 bits = 1 byte.
  2. 1 kilobyte (kB) = 1000 bytes; 1 MB = 1000 kB; 1 GB = 1000 MB; 1 TB = 1000 GB.
  3. To change to a smaller unit, multiply. To change to a larger unit, divide.
  4. Bytes to bits: × 8.
  5. Binary prefixes: 1 kibibyte (KiB) = 1024 bytes, 1 MiB = 1024 KiB.

CAUTIONUse 1000 unless the question uses kibi, mebi or gibi.

Example exam question

A file is 2.5 MB. Calculate its size in (a) bytes and (b) bits.
[2 marks]
  1. (a) 2.5 × 1000 × 1000 = 2,500,000 bytes
  2. (b) 2,500,000 × 8

Answer: (a) 2,500,000 bytes (b) 20,000,000 bits

Network security

Paper 2 · 4 marks · 1.1% of all marks · in 1 of 4 papers

The picture ideaEach security method guards a different door: who you are, what can get in, which devices can join, and whether stolen data can be read.

Explanation (ASD-STE100 style)

Network security protects data that travels between devices. AQA tests authentication, encryption, firewalls and MAC address filtering.

  1. Authentication checks a user's identity: passwords, biometrics, two-step checks.
  2. Encryption scrambles data with a key. Without the key it cannot be read.
  3. A firewall checks traffic coming in and going out against rules, and blocks unauthorised traffic.
  4. MAC address filtering only lets devices with listed MAC addresses connect.
  5. Use several methods together.

CAUTIONEncryption does not stop data being intercepted. It stops it being understood.

Example exam question

A school network uses Wi-Fi. Explain how encryption and MAC address filtering help to keep it secure.
[4 marks]
  1. Encryption scrambles data sent over the Wi-Fi
  2. Data that is intercepted cannot be understood without the key
  3. MAC filtering keeps a list of allowed device addresses
  4. Devices not on the list cannot connect to the network

Answer: Encryption makes intercepted data unreadable; MAC filtering blocks unknown devices

Character encoding

Paper 2 · 2 marks · 0.6% of all marks · in 1 of 4 papers

The picture ideaCharacter codes are in alphabetical order, so if you know one code you can count on to any letter.

Explanation (ASD-STE100 style)

Each character is stored as a binary code from a character set. AQA tests ASCII, Unicode and working out codes.

  1. ASCII uses 7 bits, so it has 2⁷ = 128 characters.
  2. Codes are in order: 'A' = 65, 'B' = 66 … 'a' = 97.
  3. To find a code, count on from a known code.
  4. Unicode uses more bits, so it can represent characters from every language and emojis.
  5. The first 128 Unicode codes are the same as ASCII.

CAUTIONThe digit '7' is not stored as 7. Its ASCII code is 55.

Example exam question

The ASCII code for 'A' is 65. (a) What is the code for 'G'? (b) Why does Unicode need more bits than ASCII?
[3 marks]
  1. (a) G is 6 letters after A: 65 + 6
  2. = 71
  3. (b) Unicode represents many more characters (all languages, symbols), so it needs more bits per character

Answer: (a) 71 (b) more characters need more bits
