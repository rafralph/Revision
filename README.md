# GCSE revision guides

A small revision website with one guide per subject. Every topic is ranked by how many marks it gets in real AQA past papers, and has a short video, a plain-English explanation, a diagram and a worked exam question.

- `index.html` – home page with the subject menu
- `maths/` – AQA GCSE Maths (8300) Higher: 36 topics from 24 papers
- `combined-science/` – AQA GCSE Combined Science: Trilogy (8464) Higher: rankings for all three sciences; Biology guides
- `computer-science/` – AQA GCSE Computer Science (8525, Python): 27 topics from 4 papers

Each subject folder has its own `index.html` and `videos/` folder.
