Quadratic sequences: nth term and proof

In-depth topic · 4 parts · 9 diagrams · 11 worked examples · 13 practice questions

Key factsPart 1Part 2Part 3Part 4Watch outPracticeTick off

Key facts

  • A sequence is quadratic when the second differences are constant
  • nth term = an² + bn + c, where a = second difference ÷ 2
  • Subtract an² from the terms; what is left is linear (bn + c) or a constant
  • Shortcut: 2a = 2nd difference, 3a + b = first 1st difference, a + b + c = first term
  • Proof: write the general term with n, then use even = 2k and odd = 2k + 1

Part 1Spotting a quadratic sequence

In a linear sequence (like 3, 7, 11, 15) the gap is always the same. In a quadratic sequence the gaps change, but the gaps between the gaps (the second differences) are the same.

The simplest quadratic sequence is the square numbers: 1, 4, 9, 16, 25. Gaps: 3, 5, 7, 9. Second differences: 2, 2, 2.

That is where the "n²" comes from. Any quadratic sequence has an n² term. Once you know the second difference you can find the next terms without a formula: add the next gap.

Part 2Finding the nth term: an² + bn + c

Method (example: 4, 11, 22, 37, 56):

  1. Find the second difference: 4. Halve it: a = 2, so the sequence starts 2n².
  2. Write out 2n² for n = 1, 2, 3...: 2, 8, 18, 32, 50.
  3. Subtract from the sequence: 4 − 2 = 2, 11 − 8 = 3, 22 − 18 = 4, 37 − 32 = 5, 56 − 50 = 6.
  4. The leftover 2, 3, 4, 5, 6 is linear: n + 1.
  5. Add the parts: 2n² + n + 1. Check: n = 3 gives 18 + 3 + 1 = 22 ✓.

If the leftover is the same number every time, it is just a constant (e.g. 2n² + 1).

Shortcut: for an² + bn + c, the first term is a + b + c, the first gap is 3a + b, and the second difference is 2a. Solve from the bottom up.

Find the nth term of 3, 9, 19, 33, 51.

  1. 1st differences 6, 10, 14, 18; 2nd difference 4 → a = 2
  2. 2n²: 2, 8, 18, 32, 50

Example 4 Exam-style

Find the nth term of 4, 11, 22, 37, 56.

  1. 2nd difference 4 → 2n²
  2. Leftover 2, 3, 4, 5, 6 → n + 1

Answer: 2n² + n + 1

Example 5 Exam-style

Find the nth term of 5, 8, 9, 8, 5.

  1. 1st differences 3, 1, −1, −3; 2nd difference −2 → a = −1
  2. −n²: −1, −4, −9, −16, −25
  3. Leftover: 6, 12, 18, 24, 30 → 6n

Answer: −n² + 6n

Part 3Using the nth term

Once you have the nth term you can answer three kinds of question:

  • Find a term: substitute n. The 10th term of 2n² + n + 1 is 200 + 10 + 1 = 211.
  • Which term is it? Set the nth term equal to the number and solve the quadratic. n must be a positive whole number.
  • Is it in the sequence? Solve the same way. If n is not a positive whole number, the number is not in the sequence.

Remember: if the 7th term is 106, then n = 7 and the term is 106. Do not mix up n (the position) and the term (the value).

  1. 2(10²) + 10 + 1 = 200 + 11

Example 7 Exam-style

Which term of 2n² + n + 1 is 106?

  1. 2n² + n + 1 = 106 → 2n² + n − 105 = 0
  2. (2n + 15)(n − 7) = 0
  3. n = 7 (n = −7.5 is not allowed)

Answer: The 7th term

Example 8 Exam-style

Is 50 a term of the sequence 2n² + 1?

  1. 2n² + 1 = 50 → n² = 24.5
  2. n = √24.5 = 4.95… (not a whole number)

Answer: No

Part 4Proof with sequences

A proof shows something is true for every term, not just the ones you tested. Use algebra:

  • Write the general term with n (and the next term with n + 1 if needed).
  • Expand and simplify.
  • Show the result has the property: even = 2 × (whole number), odd = 2 × (whole number) + 1, multiple of k = k × (whole number), always positive = (something)² + positive number.
  • Finish with a sentence.

Useful facts: n and n + 1 are consecutive, so one of them is even, which makes n(n + 1) always even. A square is never negative, so (n − 2)² + 1 is always at least 1.

Why do we halve the second difference? For an² + bn + c, the gap between term n and term n + 1 is 2an + a + b. The gap between gaps is 2a. So the second difference is always 2a.

Diagrams

Worked examples

Example 9 Standard

Prove that every term of n² + 3n is even.

  1. n² + 3n = n² + n + 2n = n(n + 1) + 2n
  2. n(n + 1) is two consecutive numbers multiplied, so it is even
  3. 2n is even; even + even = even

Answer: Every term is even

Example 10 Exam-style

Prove that the difference between consecutive terms of n² + 3n + 1 is always even.

  1. T(n + 1) = (n + 1)² + 3(n + 1) + 1 = n² + 5n + 5
  2. T(n + 1) − T(n) = 2n + 4 = 2(n + 2)

Answer: 2(n + 2) is a multiple of 2, so always even

Example 11 Exam-style

Prove that every term of n² − 4n + 5 is positive.

  1. Complete the square: (n − 2)² − 4 + 5 = (n − 2)² + 1
  2. (n − 2)² ≥ 0, so (n − 2)² + 1 ≥ 1

Answer: Every term is at least 1, so positive

Watch out for

  • Using the second difference as a, without halving it.
  • Subtracting the wrong way round: work out (sequence) − an², not an² − (sequence).
  • Getting the sign wrong when the second difference is negative (a is then negative).
  • Mixing up n (the position) and the term (the value).
  • Accepting a negative or decimal n when checking whether a number is in a sequence.
  • In a proof, only testing numbers. You must use algebra and finish with a sentence.

Q1Warm-up

Find the next two terms of 2, 6, 12, 20, 30.

  1. Gaps 4, 6, 8, 10 → 12, 14

Answer: 42, 56

Q3Warm-up

Write the first three terms of n² + 2.

Show answer
  1. n = 1, 2, 3

Answer: 3, 6, 11

Q4Standard

Find the nth term of 2, 6, 12, 20, 30.

Show answer
  1. 2nd difference 2 → n²
  2. Leftover: 1, 2, 3, 4, 5 → n

Answer: n² + n

Q5Standard

Find the nth term of 3, 12, 27, 48, 75.

Show answer
  1. 2nd difference 6 → 3n²
  2. Leftover: 0

Answer: 3n²

Q6Standard

Find the nth term of 6, 15, 28, 45, 66.

Show answer
  1. 2nd difference 4 → 2n²: 2, 8, 18, 32, 50
  2. Leftover: 4, 7, 10, 13, 16 → 3n + 1

Answer: 2n² + 3n + 1

Q7Standard

Find the nth term of 7, 10, 11, 10, 7.

Show answer
  1. 2nd difference −2 → −n²: −1, −4, −9, −16, −25
  2. Leftover: 8, 14, 20, 26, 32 → 6n + 2

Answer: −n² + 6n + 2

Q8Exam-style

Which term of n² + n is 156?

Show answer
  1. n² + n − 156 = 0
  2. (n + 13)(n − 12) = 0

Answer: The 12th term

Q9Exam-style

Is 75 a term of n² + 2n? Explain.

Show answer
  1. n² + 2n − 75 = 0
  2. Discriminant 4 + 300 = 304, not a square number
  3. So n is not a whole number

Answer: No

Q10Exam-style

Find the first term of 2n² + 1 that is greater than 500.

Show answer
  1. 2n² + 1 > 500 → n² > 249.5
  2. n = 15 gives 451; n = 16 gives 513

Answer: 513 (the 16th term)

Q11Exam-style

Prove that every term of n² + n is even.

Show answer
  1. n² + n = n(n + 1)
  2. n and n + 1 are consecutive, so one is even

Answer: The product is even

Q12Exam-style

Prove that the sum of two consecutive square numbers is always odd.

Show answer
  1. n² + (n + 1)² = 2n² + 2n + 1
  2. = 2(n² + n) + 1

Answer: 2 × (whole number) + 1, so odd

Q13Exam-style

Prove that every term of 4n² + 4n + 1 is an odd square number.

Show answer
  1. 4n² + 4n + 1 = (2n + 1)²
  2. 2n + 1 is odd

Answer: It is the square of an odd number
