Quadratic sequences: nth term and proof

In-depth topic · 6 parts · 13 diagrams · 22 worked examples · 18 quick-check questions · 20 practice questions

Key factsPart 1Part 2Part 3Part 4Part 5Part 6Exam tipsWatch outPracticeTick off

Key facts

  • A sequence is quadratic when the second differences are constant (and not zero)
  • nth term = an² + bn + c, where a = second difference ÷ 2
  • Method 1: subtract an² from each term; what is left is bn + c (or just c)
  • Method 2: 2a = 2nd difference, 3a + b = first 1st difference, a + b + c = first term
  • n is the position (1, 2, 3 …), always a positive whole number; the term is the value
  • Proof: even = 2k, odd = 2k + 1; n(n + 1) is always even; a square is never negative

Part 1 of 6Spotting and continuing a quadratic sequence

In a linear sequence (3, 7, 11, 15 …) the gap is always the same. In a quadratic sequence the gaps change, but the gaps between the gaps (second differences) stay the same.

The simplest one is the square numbers: 1, 4, 9, 16, 25. Gaps: 3, 5, 7, 9. Second differences: 2, 2, 2. That is where the n² comes from.

Method: write the first differences under the gaps, then the second differences under those. Constant second differences → quadratic.

Continuing the sequence

You do not need a formula. Extend the second differences, then the first differences, then the terms. For 4, 7, 12, 19, 28: gaps 3, 5, 7, 9 → next gap 11 → next term 39.

Finding a missing term

2, 7, ?, 23, 34: call the missing term x. The gaps are 5, x − 7, 23 − x, 11. The second differences must be equal. The gaps go up by the same amount each time: 5, 7, 9, 11 (second difference 2). So x = 7 + 7 = 14.

Part 2 of 6Finding the nth term, method 1: subtract an²

Every quadratic sequence has an nth term of the form an² + bn + c.

  1. Find the second difference. Halve it to get a.
  2. Write out an² for n = 1, 2, 3, 4, 5.
  3. Subtract: sequence − an².
  4. The leftover is linear (bn + c) or a constant (c). Find its nth term.
  5. Add: an² + (leftover). Check with one term.

Example: 4, 11, 22, 37, 56. Second difference 4, so a = 2. 2n²: 2, 8, 18, 32, 50. Leftover: 2, 3, 4, 5, 6 = n + 1. So the nth term is 2n² + n + 1. Check n = 3: 18 + 3 + 1 = 22 ✓.

Negative second difference

5, 8, 9, 8, 5: gaps 3, 1, −1, −3; second difference −2, so a = −1. −n²: −1, −4, −9, −16, −25. Leftover: 5 − (−1) = 6, 8 − (−4) = 12, 18, 24, 30 = 6n. nth term: −n² + 6n.

Why halve?

n² on its own has second difference 2 (look at the square numbers). So an² has second difference 2a. Part 6 proves this.

Part 3 of 6Finding the nth term, method 2: the 2a, 3a + b, a + b + c shortcut

Put n = 1, 2, 3 into an² + bn + c and look at the differences:

  • First term: a + b + c
  • First 1st difference: (4a + 2b + c) − (a + b + c) = 3a + b
  • Second difference: 2a
Match these to your difference table and solve from the bottom up: 2a gives a → 3a + b gives b → a + b + c gives c.

Example: 7, 10, 11, 10, 7. 2a = −2 → a = −1. 3a + b = 3 → −3 + b = 3 → b = 6. a + b + c = 7 → −1 + 6 + c = 7 → c = 2. nth term: −n² + 6n + 2.

The zeroth term trick

c is the value of the "0th term" (put n = 0). Work the differences backwards one step. For 4, 13, 26, 43: gaps 9, 13, 17, so the gap before 9 is 5, and the 0th term is 4 − 5 = −1. So c = −1.

Part 4 of 6Sequences from patterns and unknown coefficients

Many questions show a pattern of dots, tiles or matchsticks. Count each pattern to get the sequence, then find the nth term as usual.

Example: the patterns below have 3, 8, 15, 24 dots. Count them: 3, 8, 15, 24 → gaps 5, 7, 9 → a = 1 → leftover 2, 4, 6, 8 = 2n → n² + 2n (which is n(n + 2): a rectangle n by n + 2).

Then use it: pattern 20 has 20² + 40 = 440 dots.

Unknown coefficients

"The nth term is an² + b. The 2nd term is 14 and the 5th term is 77. Find a and b." Substitute to get simultaneous equations:

n = 2: 4a + b = 14   n = 5: 25a + b = 77. Subtract: 21a = 63 → a = 3, b = 2. So 3n² + 2.

Part 5 of 6Using the nth term

Once you have the nth term, you can answer four kinds of question:

  • Find a term: substitute n. 10th term of 2n² + n + 1 = 200 + 10 + 1 = 211.
  • Which term is it? Set nth term = value, rearrange to … = 0 and solve. n must be a positive whole number.
  • Is it in the sequence? Same method. Not a positive whole number → not in the sequence.
  • First term over a value: solve the inequality, or try values of n either side.

2n² + n + 1 = 106 → 2n² + n − 105 = 0 → (2n + 15)(n − 7) = 0 → n = 7 (ignore n = −7.5). So 106 is the 7th term.

Is 50 in 2n² + 1? 2n² = 49 → n² = 24.5 → n = 4.95… Not whole, so no.

How many terms of n² + n are less than 200? n = 13 gives 182; n = 14 gives 210. So 13 terms.

Part 6 of 6Proof with sequences

A proof shows something is true for every term, not just the ones you tried. Testing numbers is not a proof (but it is a good way to get an idea).

  1. Write the general term using n (and term n + 1 if you need the next term).
  2. Expand and simplify.
  3. Rearrange into the target form: even = 2 × (whole number), odd = 2 × (whole number) + 1, multiple of k = k × (…), positive = (…)² + positive number, square = (…)².
  4. Finish with a sentence.

Useful facts

  • n and n + 1 are consecutive, so one of them is even: n(n + 1) is always even.
  • A square is never negative, so (n − 2)² + 1 ≥ 1.

Why a = half the second difference (a full proof)

Let T(n) = an² + bn + c. Then T(n + 1) − T(n) = a(2n + 1) + b = 2an + a + b. This gap goes up by 2a each time n goes up by 1. So the second difference is always 2a.

Disproving: a counterexample

To show a claim is false, one example is enough. "n² + n + 41 is always prime": when n = 40 it is 1681 = 41², which is not prime.

Example 19 Standard

Prove that every term of n² + 3n is even.

  1. n² + 3n = n(n + 1) + 2n
  2. n(n + 1) is even (consecutive numbers); 2n is even

Prove that the difference between consecutive terms of n² + 3n + 1 is always even.

  1. T(n + 1) = n² + 5n + 5
  2. T(n + 1) − T(n) = 2n + 4 = 2(n + 2)

Answer: Always a multiple of 2

Prove that every term of n² − 4n + 5 is positive.

  1. (n − 2)² − 4 + 5 = (n − 2)² + 1
  2. (n − 2)² ≥ 0

Answer: Every term ≥ 1, so positive

Exam tips

  • Always draw the difference table neatly: 1st differences between terms, 2nd differences between those.
  • After finding the nth term, check it with two terms (e.g. n = 1 and n = 3). It takes 20 seconds.
  • In "is it a term?" questions, show the solving and finish with a sentence: "n is not a whole number, so no".
  • In proofs, define what you use ("let n be a positive integer") and finish with a conclusion sentence.
  • If a pattern question is hard to count, look for the shape: rectangles give n(n + k).

Watch out for

  • Using the second difference as a, without halving it.
  • Subtracting the wrong way: work out (sequence) − an², not an² − (sequence).
  • Getting the sign wrong when the second difference is negative (a is then negative).
  • Mixing up n (the position) and the term (the value).
  • Accepting a negative or decimal n when checking whether a number is in a sequence.
  • In a proof, only testing numbers. You must use algebra and finish with a sentence.
