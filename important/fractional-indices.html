Fractional indices

In-depth topic · 4 parts · 8 diagrams · 10 worked examples · 13 practice questions

Key factsPart 1Part 2Part 3Part 4Watch outPracticeTick off

Key facts

  • a1/2 = √a, a1/3 = ∛a, a1/n = the nth root of a
  • am/n = (ⁿ√a)m: the bottom is the root, the top is the power
  • Do the root first; the numbers stay small
  • a−m/n = 1am/n: negative → flip, then root, then power
  • To solve 8x = 4, write both as powers of 2: 23x = 22, so x = ⅔

Part 1Unit fractions are roots

What could 9½ mean? Use the index laws: 9½ × 9½ = 9½ + ½ = 91 = 9.

So 9½ is a number that multiplies by itself to make 9. That is the square root: 9½ = 3.

In the same way, 8⅓ × 8⅓ × 8⅓ = 8, so 8⅓ is the cube root of 8, which is 2.

a1/n = the nth root of a

Examples: 49½ = 7, 125⅓ = 5, 81¼ = 3 (because 3 × 3 × 3 × 3 = 81), 321/5 = 2.

Part 2Other fractions: root, then power

For a power like 23, split it into two jobs. 23 = 13 × 2, so:

82/3 = (81/3)2 = 22 = 4

  • The denominator (bottom) tells you the root.
  • The numerator (top) tells you the power.

Memory trick: the root is at the roots of the fraction, at the bottom, like the roots of a tree.

Always take the root first, so the numbers stay small: 274/3 = (∛27)4 = 34 = 81. (Doing the power first, you would need the cube root of 531 441!)

Part 3Negative fractional powers

Now combine the two topics. A negative fractional power has three jobs. Use the order F-R-P:

  1. Flip (because of the minus sign).
  2. Root (the denominator).
  3. Power (the numerator).

Example: 16−3/4 → flip: (116)3/4 → fourth root: (12)3 → cube: 18.

With a fraction: (278)−2/3 → flip: (827)2/3 → cube roots: (23)2 → square: 49.

Part 4Fractional powers in algebra and equations

Roots can be written as powers, so you can use the index laws on them:

  • √x = x½   ∛x = x⅓   ∛(x2) = x2/3
  • 1√x = x−½   √xx2 = x½ − 2 = x−3/2

A power outside a bracket applies to the number and the letter: (16x8)3/4 = 163/4 × x8 × 3/4 = 8x6.

Equations: write both sides with the same base. 8x = 4 → (23)x = 22 → 3x = 2 → x = ⅔. And 9x = 27 → 32x = 33 → x = 32.

Watch out for

  • Halving instead of square-rooting: 16½ = 4, not 8.
  • Swapping root and power: in 82/3 the 3 is the root and the 2 is the power.
  • Forgetting to flip for a negative power: 25−½ = ⅕, not −5.
  • Applying the power only to the letter: (8x³)⅔ = 4x², not 8x².
  • Not changing to the same base in equations (e.g. leaving 8 and 4 instead of 2³ and 2²).
