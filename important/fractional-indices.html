Fractional indices

Key facts

  • a1/2 = √a, a1/3 = ∛a, a1/n = ⁿ√a (the nth root)
  • am/n = (ⁿ√a)m: the bottom of the fraction is the root, the top is the power
  • Root first, then power: the numbers stay small
  • a−m/n = 1am/n: negative → Flip, Root, Power (F-R-P)
  • Decimal powers: change to fractions first (0.5 = ½, 1.5 = 3/2, 0.75 = ¾)
  • Equations: write both sides as powers of the same number, then set the powers equal

Part 1 of 6Unit fractions are roots

What could 9½ mean? The index laws decide it for us. Multiply it by itself:

9½ × 9½ = 9½ + ½ = 91 = 9

So 9½ is a number which, multiplied by itself, makes 9. That is the square root: 9½ = 3.

In the same way 8⅓ × 8⅓ × 8⅓ = 81, so 8⅓ is the cube root of 8, which is 2.

Rule: a1/n = ⁿ√a. The denominator tells you which root.

Roots of negative numbers and decimals

Odd roots of negative numbers are fine: (−8)⅓ = −2, because (−2)³ = −8. Even roots of negatives (like (−4)½) do not exist at GCSE.

For decimals, think of the fraction: 0.04½ = √0.04 = 0.2 (because 0.2 × 0.2 = 0.04).

Spot it in the exam

"Write down the value of 64⅓" (1 mark). You need your powers table: squares to 15², cubes to 10³, and the powers of 2 and 3.

Part 2 of 6Other fractions: root, then power

For a power like 23, split it into two jobs. Because 23 = 13 × 2, the power law gives:

82/3 = (81/3)2 = 22 = 4

Rule: am/n = (ⁿ√a)m. Bottom = root, top = power. Memory trick: the root is at the roots of the fraction, at the bottom, like the roots of a tree.

You could do the power first: (82)1/3 = ∛64 = 4. Same answer, but bigger numbers. With 274/3, power-first needs ∛531 441! So always root first: (∛27)4 = 34 = 81.

Spot it in the exam

"Work out 163/4" or "Find the value of 323/5". Write the root step on its own line.

Part 3 of 6Fractions and decimals as the base or the power

Fraction as the base: apply the power to the top and to the bottom separately.

(49)½ = √4√9 = 23.   (827)2/3 = (23)2 = 49.   (1681)3/4 = (23)3 = 827.

Decimal as the base: change to a fraction. 0.253/2 = (14)3/2 = (12)3 = 18.

Decimal as the power: change the power to a fraction. 0.5 = ½, 1.5 = 32, 0.75 = ¾, 2.5 = 52.

So 250.5 = 25½ = 5,   161.5 = 163/2 = 43 = 64,   810.75 = 81¾ = 33 = 27.

Spot it in the exam

Questions with decimals in the power look scary but are just fractions in disguise. Converting is the first mark.

Part 4 of 6Negative fractional powers

A negative fractional power has three jobs. Do them in the order F-R-P:

  1. Flip (deal with the minus sign: one over).
  2. Root (the denominator).
  3. Power (the numerator).

16−3/4 → flip: (116)3/4 → fourth root: (12)3 → cube: 18.

(278)−2/3 → flip: (827)2/3 → cube root: (23)2 → square: 49.

0.001−⅓ → flip: 1000⅓ → cube root: 10.

The order of R and P does not change the answer, but F-R-P keeps the numbers smallest.

Spot it in the exam

These are typical 2-mark, grade 7–8 questions. Writing the flipped version on its own line gets the first mark.

Part 5 of 6Fractional powers in algebra (and links to surds)

Every root can be written as a power, and then all the index laws work:

  • √x = x½,   ∛x = x⅓,   ∛(x2) = x2/3
  • x√x = x1 × x½ = x3/2
  • 1√x = x−½,   1∛x = x−⅓,   √xx2 = x½ − 2 = x−3/2

A power outside a bracket applies to the number and each letter:

(16x8)3/4 = 163/4 × x8 × ¾ = 8x6.   (27x6y3)⅓ = 3x2y.

Link to surds

A fractional power of a non-square number gives a surd: 8½ = √8 = 2√2, and 12½ = 2√3. Also 23/2 = 2√2.

Spot it in the exam

"Write … as a single power of x" or "Simplify fully". Change every root into a power first, then add or subtract the powers.

    Part 6 of 6Solving equations with fractional powers

    Type 1: the unknown is in the power. Write both sides as powers of the same number.

    8x = 4 → (23)x = 22 → 3x = 2 → x = ⅔.   9x = 27 → 32x = 33 → x = 32.

    27x+1 = 9 → 33x+3 = 32 → 3x + 3 = 2 → x = −⅓.

    Type 2: the unknown is the base. Undo the power by raising both sides to the reciprocal power.

    x3/2 = 27 → x = 272/3 = 9.   x−½ = ¼ → x½ = 4 → x = 16.

    Type 3: find n. √2 × 8 = 2n → 2½ × 23 = 27/2 → n = 72.

    Spot it in the exam

    These are often the last parts of an indices question (3 marks). Write the "same base" line clearly.

    Exam tips

    • Write the root step and the power step on separate lines: each can earn a mark.
    • Learn the powers table (squares, cubes, powers of 2 and 3). Most questions use these numbers.
    • For negative fractional powers, say F-R-P in your head every time.
    • In equations, change every number to the same base before using any rules.
    • Check: 16¾ must be between 16½ = 4 and 161 = 16. If your answer is outside, something is wrong.

    Watch out for

    • Halving instead of square-rooting: 16½ = 4, not 8.
    • Swapping root and power: in 82/3 the 3 is the root and the 2 is the power.
    • Forgetting to flip for a negative power: 25−½ = ⅕, not −5.
    • Applying the power only to the letter: (8x³)⅔ = 4x², not 8x².
    • Leaving decimal powers as decimals: change 1.5 to 3/2 first.
    • Not changing to the same base in equations (e.g. leaving 8 and 4 instead of 2³ and 2²).
