Negative indices

In-depth topic · 4 parts · 8 diagrams · 9 worked examples · 13 practice questions

Key factsPart 1Part 2Part 3Part 4Watch outPracticeTick off

Key facts

  • a0 = 1 (any number except 0)
  • a−n = 1an: a negative power means one over (the reciprocal)
  • (ab)−n = (ba)n: flip the fraction, then make the power positive
  • Index laws still work: am × an = am+n, am ÷ an = am−n, (am)n = amn
  • A negative power never makes the answer negative: 2−3 = ⅛, not −8

Part 1Where negative powers come from

Look at the powers of 2 going down. Each step divides by 2:

23 = 8, 22 = 4, 21 = 2, 20 = 1

Keep going with the same rule and you get 2−1 = ½, 2−2 = ¼, 2−3 = ⅛. So a negative power just means "keep dividing": it is one over the positive power.

a−n = 1an

The index laws agree. 23 ÷ 25 = 23−5 = 2−2. But also 8 ÷ 32 = ¼. So 2−2 = ¼.

The same pattern explains why a0 = 1: 53 ÷ 53 = 50, and anything divided by itself is 1.

Part 2Negative powers of fractions and decimals

One over a fraction is the fraction flipped upside down (its reciprocal): one over ⅔ is 32. So for a fraction:

  1. Flip the fraction (this deals with the minus sign).
  2. Apply the power to the top and the bottom.

Example: (23)−2 → (32)2 = 94.

For a decimal, change it into a fraction first: 0.5 = ½, so 0.5−3 = 23 = 8. And 0.2 = 15, so 0.2−2 = 52 = 25.

A whole number is a fraction over 1: 4−1 = (41)−1 = 14.

Part 3Index laws with negative powers

All the index laws still work. Be careful with the signs when you add and subtract.

  • Multiply → add the powers: x4 × x−7 = x4 + (−7) = x−3.
  • Divide → subtract: x−2 ÷ x−6 = x−2 − (−6) = x4.
  • Power of a power → multiply: (x−2)3 = x−6.

Watch what the power belongs to. In 3x−2 only the x has the power, so it is 3x2. In (3x)−2 everything in the bracket has it, so it is 19x2.

To write 1x4 as a power: x−4. To write 5x3 as a power: 5x−3.

Part 4Writing numbers as powers and solving equations

Many questions ask you to write a number as a power of a given base. Use the fact that a fraction with 1 on top is a negative power:

18 = 123 = 2−3    181 = 3−4    0.01 = 1100 = 10−2

To solve an equation like 2x = 116, make both sides powers of the same number, then the powers must be equal:

116 = 2−4, so 2x = 2−4 and x = −4.

If the bases are different (like 4 and 2), change them to the same base first: 4 = 22, so 4x = 22x.

Watch out for

  • Thinking a negative power makes the answer negative: 2−3 is ⅛, not −8.
  • Multiplying the base by the power: 2−3 is not −6.
  • Saying x0 = 0. Anything (except 0) to the power 0 is 1.
  • Applying the power to the number when there is no bracket: 3x−2 = 3/x², not 1/(3x²).
  • Sign errors when subtracting a negative power: x3 ÷ x−2 = x3 − (−2) = x5.
  • Forgetting to flip a fraction: (2/3)−2 = 9/4, not 4/9.
