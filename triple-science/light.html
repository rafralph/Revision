Reflection, refraction, lenses and colour

Physics · rank 2 of 29 · 75 marks · 7.5% of Physics marks · in 6 of 10 papers · Required practical: Reflection and refraction

Explanations 4 ways

1The picture idea

Light slows down in glass. The side of the beam that enters first slows first, so the beam turns, like a car that drives onto sand at an angle.

2Step by step

Reflection: angle of incidence = angle of reflection. Measure angles from the normal. A smooth surface gives specular reflection. A rough surface gives diffuse reflection.

Refraction: light changes speed when it enters a new material. If it enters at an angle, it changes direction. Into a denser material, it bends towards the normal.

Lenses: a convex lens brings light to a focus at the principal focus. A concave lens spreads light out. Magnification = image height ÷ object height.

A convex lens can make a real image. A concave lens always makes a virtual image.

Colour: an object looks red because it reflects red light and absorbs the other colours. A filter only lets one colour through.

CAUTIONMagnification has no unit. Both heights must be in the same unit.

3Another way to see it

A convex (converging) lens bends light rays inwards to meet at a focal point, like a magnifying glass focusing sunlight. A concave (diverging) lens spreads rays out.

Magnification = image height ÷ object height. It has no units.

Colour: a red object reflects red light and absorbs all other colours. In green light it has no red to reflect, so it looks black. A filter lets through only its own colour.

A mirror gives specular reflection (one direction). Paper gives diffuse reflection (scattered in all directions).

4Watch out for

  • Giving magnification units. It is a ratio, so no units.
  • Saying a red object 'turns' light red. It reflects only the red part.
  • Saying a red filter makes light red. It absorbs other colours and lets red through.
  • Mixing up real images (on a screen, upside down) and virtual images (cannot be projected).
  • Drawing rays without arrows.

Worked examples 3

Example 1 Warm-up

What colour does a red book look in green light?

  1. It only reflects red. There is no red in green light.

Answer: Black

Example 2 Standard

An object is 2.0 cm tall. Its image is 6.0 cm tall. Calculate the magnification.

  1. 6.0 ÷ 2.0

Answer: 3 (no units)

Example 3 Exam-style [4 marks]

(a) A lens makes an image 4.5 cm tall of an object 1.5 cm tall. Calculate the magnification. (b) A blue book is lit with red light only. Explain why it looks black.

  1. (a) Magnification = image height ÷ object height
  2. = 4.5 ÷ 1.5 = 3
  3. (b) The blue book reflects only blue light; it absorbs the red light
  4. No light is reflected to the eye, so it looks black

Answer: (a) 3; (b) red is absorbed, nothing reflected

Q5Exam-style

Answer: Virtual, upright and magnified (on the same side as the object)
